# Archived worlds

These manifests ran under earlier kernels. They are kept as reading material, not
as identities: a kernel change is a new world (Chapter II §II.b), so the running
kernel does not load them and `factorylab wake` does not match ledgers against
them. A ledger born under one is read with its own key by the key-only readers
(`factorylab postmortem`, `factorylab versions`).
