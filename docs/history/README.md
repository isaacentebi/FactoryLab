# History

These are the specs and plans the build followed, kept for provenance and nothing
else. Every one of them is superseded: by the code in this repository, by
`docs/manifest.md` for what a manifest may say, and by
`docs/build-spec-v0.8-round2.md` for the rules the code now implements.

Nothing here is binding. Where a file disagrees with the code, the code is right.
Where it describes a plan, a stage of the build or a deliberate gap, read it as a
record of what was intended at the time, not as a claim about this commit.
`outputs/` holds the earliest design rationale, written before the first spec.
