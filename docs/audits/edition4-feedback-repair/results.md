# Feedback repair and behavioral interpretability

The repair reached the live population, but this run does not establish learning or emergent collaboration. It also exposed a further context defect: grounded meta requests offered optional registrations while omitting the capability instructions needed to construct them. Do not classify those failures as unwillingness.

## What changed and what was verified

- Final grounded findings now enter the owning producer's existing inbox, separately from provisional verdicts. Supported, contrary and unknown cases pass the real evaluator-to-inbox-to-next-request regression. Unknown remains unscored.
- The charter view separates actual waiting amendments from an eligibility boundary. An empty queue no longer looks like a scheduled charter change.
- Invocation metadata hashes the stable prefix and effective leading messages. It records no additional prompt prose and changes no provider caching behavior.
- A terminated-run analyzer separates unique decisions from repeated contract emissions, declared actions from executed tools, pre-dispatch rejected sections from dispatched calls, and addressed findings from acknowledged receipt. Ordered chains and same-directory input checks were independently reviewed.

Final checks: 2,148 check-tier tests passed in 21.51 seconds; the affected gate selection passed four tests; the integrated runtime-to-trace gate passed after the analyzer corrections. Ruff and diff checks passed. The four-call answer-budget fixture cost $0.006024: 4,096 tokens yielded 2/2 valid answers, 8,192 yielded 1/2. This did not reproduce the original live failure and did not justify raising the allowance. Reasoning and output allowances stayed unchanged.

The live runtime was frozen before dispatch; the postmortem analyzer was tightened afterward. See `run-preflight.json`, `source.patch`, `analysis-verification.json` and `protocol.md` for identities and bounds. No source change reached the running population.

Observed actions can be described, but population-level learning or comparative rates remain inconclusive. The previous run differs in source and duration; this is not a matched causal comparison.

## Context, instructions and communication

Compact does not mean small. Ordinary producer prompts grew from roughly 45–46k characters to 55–74k. Judge-fidelity reached 95,896 characters; its median input was 24,175 tokens. Judge-consequence ended at 82,288 characters. The shared stable prefix alone was 25,681 characters. The late judge-fidelity `YOU` block was 34,270 characters despite its last retained working state being about 1.5k characters. See `model-context-summary.json`; continuation token counts and root prompt character counts are not always the same request.

The inbox in `runtime/continuity.py` renders the oldest eight unread bodies until acknowledged. This can repeatedly carry old text and leave newer feedback outside the inline window. Only opportunity acknowledged items in the observed final chains. There is no exported per-invocation record of every inline item, so absence of acknowledgment remains unknown exposure. Replacing repeated bodies with concise, addressable entries and a complete retrieval route is a better next context experiment than simply raising a token cap. Preserve the participant's own working state and the evidence required by the current commission.

A specific missing-instruction path was found during the postmortem. Grounded `_meta_step` removes `world` and `charter` to protect the frozen evaluation standard. The requests for decisions 159 and 383 consequently had zero stable-prefix and world-update content. Their `register` schema requires only a `kind` enum. The full proposal grammar exists in schematics, but was not carried in these requests. They returned observation/challenge kind-only objects; downstream application rejected missing IDs and challenge fields (sequences 3915, 3916 and 9165). The next repair must separate operational capability context from the frozen adjudication record, rather than restore a current charter as the grading standard or call these stubs disobedience. This newly found gap is not repaired by the patch tested above.

Direct address already exists: sender-funded, bounded messages to a named live participant, no recipient charge or forced wake, and a right to ignore. Notes provide public rented storage. A forum could be composed from these primitives. Zero attempts in this run does not establish that the transport is broken or that a message board would create cooperation. The useful next comparison is whether actors can discover another participant, deliver an addressed artifact or offer, retrieve the response and reuse the result, without being rewarded merely for communicating. Scripted commissions prove the path; an uncommissioned population run tests whether it chooses to use it.

Of 139 root invocations, 22 were malformed and one failed. Twenty malformed calls ended at length or reasoning-only; judge-fidelity had 15 malformed/36 roots and mechanism six/12. Other models have different roles and requests, so these are workload observations, not a matched ranking. Luna reported zero cached tokens in this live sample; GLM reported hits in many calls. Local prefix hashes were stable within ordinary request classes. This does not establish why the upstream Luna cache missed.

## Next experiments, not more institutions

1. Repair the grounded-review capability bootstrap while preserving frozen judging evidence. Prove complete registration discovery/validation offline for the exact request path.
2. Reduce repeated inbox/reference payloads while preserving current evidence, ownership, pending effects and retrieval. Measure input tokens, bill, valid completion and retrieval success against the same tasks; do not disable reasoning.
3. Exercise address→recipient retrieval→reply→artifact use offline, then test voluntary use without a cooperation bonus or required message count. A message board is not yet the justified intervention.
4. Size longer live tests by delivered feedback cycles. The real clock with injected 77-second tick work delivers 47 ticks in one hour and 281 in six; no provider calls were used for that preflight. Current dispatch is serial. Governance needs at least 180 ticks plus a consequence window, not merely a shorter tick setting.

The rehearsal disables seller purchases and treasury transfers. It cannot test external income buying operation. More nominal capital or a 10× compute allocation cannot by itself remove that experimental boundary, malformed returns, missing capability instructions or serial latency.
